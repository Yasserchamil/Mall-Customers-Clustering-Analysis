## 📘 Overview  

This project applies K-Means clustering to identify meaningful customer groups based on **Age**, **Annual Income**, and **Spending Score**.  
It demonstrates strong skills in **data cleaning**, **exploratory data analysis**, **visualization**, and **unsupervised machine learning**.

The analysis was conducted using **Google Colab**.

---

## 🎯 Objectives  

- Clean and prepare the dataset  
- Visualize distributions of Age, Income, and Spending Score  
- Explore relationships using heatmaps and pairplots  
- Apply the Elbow Method to determine the optimal number of clusters  
- Perform customer segmentation using K-Means  
- Visualize and interpret clusters  

---

## 🧠 Key Insights  

- Customers form clear clusters based on income and spending patterns  
- Weak correlations between features indicate clustering is effective  
- Younger customers tend to have higher spending scores  
- The optimal number of clusters is **5** based on the Elbow Method  
- Segments show distinct marketing and business opportunities
